# 🌐 Website Health Checker

A beginner-friendly QA automation tool built using **Python and Playwright** to automatically check the health and basic quality of a website.

## 📌 Project Overview

Website Health Checker allows a QA engineer to enter a website URL and automatically perform several validation checks.

The tool helps identify broken links, HTTP errors, missing images, page title issues, and link timeouts. It also measures the website's page load time and generates an HTML test report.

## 🚀 Features

- ✅ Website HTTP status validation
- 🔗 Broken link detection
- ⏱️ Link timeout detection
- ⚡ Page load time measurement
- 🏷️ Page title validation
- 🖼️ Missing/broken image detection
- 🚨 HTTP 4xx/5xx error monitoring
- 📊 Automatic HTML test report generation

## 🛠️ Technologies Used

- Python
- Playwright
- HTML
- CSS
- Google Chrome
